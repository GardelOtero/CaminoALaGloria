# Camino a la Gloria

Simulador de carrera futbolística construido con Vue y ASP.NET Core.

## Ejecutar

1. `dotnet run --project backend/CaminoALaGloria.Api`
2. `cd frontend && npm.cmd install && npm.cmd run dev`

La API inicia en `http://localhost:5098` y el cliente en `http://localhost:5173`.

Consulta [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) para las reglas de producto, decisiones y próximo trabajo.
